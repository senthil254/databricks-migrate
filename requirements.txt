# Python dependencies for the FastAPI adapter (backend/).

# Pinned from the working environment (Python 3.12).  Install with:
#
#     uv venv --python 3.12 backend/.venv
#     uv pip install --python backend/.venv/bin/python -r requirements.txt
#
# or with plain pip:
#
#     python3.12 -m venv backend/.venv
#     backend/.venv/bin/pip install -r requirements.txt
#
# DO NOT ADD pyarrow.
# databricks-sql-connector will emit a warning saying pyarrow is not installed
# and that cloud-fetch is disabled.  That warning is expected and harmless.
# Installing pyarrow changes the connector's fetch path and makes the backend
# test suite die with a segmentation fault (exit 139) inside
# tests/test_databricks_mcp_client.py.  The application does not need it.
#
# Note: this project also requires the `databricks` CLI with the Lakebridge
# labs extension installed — that is a tool, not a Python dependency.
